# Modulith Desktop 文档

本目录是 Modulith Desktop 的技术文档中心。文档按主题分册，每册既可独立阅读，也可按推荐路径顺序通读。

文档描述的是**当前代码的实际行为**。凡涉及具体行为、默认值、字段名的描述，都以代码为准；发现文档与代码不符时，以代码为准并提交修正。

## 项目定位

Modulith Desktop 是一个基于 Tauri 2 的高自由度模块化桌面框架。它的核心主张是：**需要什么功能，就加什么模块**。框架本身只提供外壳、模块生命周期、访问授权与插件运行时，具体能力全部由模块与插件提供。

产品名 `Modulith Desktop` 由 module + monolith 构成，应用标识（三枚方块 + 右下角空位）也直接对应这个主张。

扩展方式有两种，职责边界清晰：

| 方式 | 生效时机 | 适用场景 | 分发形态 |
| --- | --- | --- | --- |
| 内建模块 | 编译期 | 框架自带能力、需要深度集成前端的核心功能 | 随应用一起发布 |
| 插件 | 运行期 | 第三方扩展、用户自行安装的功能 | `.lcp` 包（zip 容器） |
